# 艾丽妮 · 提灯审阅员

明日方舟艾丽妮的第四版 Codex 宠物素材包。默认慢走、睁眼待机，悬停时轻轻摆动提灯；提供九种工作状态、十六方向视线和可选原跑步动画。

## 安装

从 [Releases](https://github.com/hhikr/irene-codex-pet/releases) 下载最新 ZIP，解压后在 PowerShell 中运行：

```powershell
& '.\install.ps1'
```

如需使用原跑步动画：

```powershell
& '.\install.ps1' -Movement run
```

安装器只更新当前用户的 Codex 宠物文件。安装后，在 Codex 宠物设置中刷新并重新选择艾丽妮。无需管理员权限。

## 动画预览

在解压目录打开 `preview.html`。预览可以切换慢走或原跑步、原生或高清图集、宿主节奏或连续循环，并查看九种状态、指针视线和悬停动作。预览页的工作流演示是页面计时器，不读取实际 Codex 任务。

## 素材

| 路径 | 用途 |
| --- | --- |
| `assets/native/` | Codex v2 兼容图集，单帧 192×208 |
| `assets/hd/` | 高清预览图集，单帧 384×416 |
| `assets/previews/` | 提灯动画与待机节奏预览 |

图集使用八列十一行。九个工作状态依次为待机、向右移动、向左移动、提灯回应、完成、失败、等待、思考与执行、结果审阅。最后两行包含十六个视线方向姿态。

## 说明

Codex 宿主控制宠物动画的播放速度与交互。本项目只提供宠物素材，不修改 Codex 应用，也不读取真实任务状态。第四版主要优化待机与提灯回应帧的发丝轮廓；其他工作动作保留原有素材。
